| Project | Description | Concepts |

## Learning Goals
- Strengthen C++ fundamentals through application rather than memorization
- Develop a strong understanding of memory, pointers, references, arrays, and containers
- Prepare for the C++ Institute CPE certification
- Progress from small exercises toward larger C++ projects
- Eventually apply C++ to physics simulations and scientific computing
